## Summary
Display Login Page Status Message

## Description
As a user, I want to see a simple "Login page loaded successfully" message when the login page opens, so I know the page is ready to use. The message should appear automatically without changing the existing login functionality. This requires only a small UI update and one basic automated test. No backend, authentication, or database changes are needed.

## Acceptance Criteria
**Note:** No explicit acceptance criteria field/section was provided in Jira. The following criteria have been inferred from the description text and should be confirmed during Phase 01 (Requirements):

1. When the login page loads, a "Login page loaded successfully" message is displayed automatically to the user (no user action required to trigger it).
2. The message appears without altering or breaking any existing login functionality (e.g., existing form fields, submit behavior, validation).
3. The change is limited to a UI-level update only - no backend, authentication, or database changes are introduced.
4. At least one basic automated test verifies that the message is displayed when the login page loads.
