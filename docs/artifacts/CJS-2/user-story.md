## Summary
Implement Simple Login Page

## Description
As a user, I want to enter my email and password and log in so that I can access the application.

**Acceptance Criteria:**

1. The page displays an Email field.
2. The page displays a Password field.
3. The page displays a Login button.
4. The user can enter an email and password.
5. When the user clicks Login, the page displays "Login successful".
6. The login behavior can use mock/local logic.
7. No backend authentication or database is required.

**Scope:**

- Simple login UI only.
- React + TypeScript + Vite.
- Basic automated test for the login interaction.

**Out of Scope:**

- Real authentication
- Backend API
- Database
- User registration
- Forgot password
- Social login
- Advanced validation
