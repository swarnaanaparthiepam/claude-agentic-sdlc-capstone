## Summary
Add Logout Button

## Description
As a user, I want to click a Logout button so that I can exit the application.

Scope:
- Simple logout UI only.
- React + TypeScript + Vite.
- Basic automated test for the logout interaction.

Out of Scope:
- Real authentication
- Backend API
- Database
- Session management
- Token handling
- User registration
- Login functionality
- Navigation to another page

## Acceptance Criteria
1. The page displays a Logout button.
2. The user can click the Logout button.
3. When the user clicks Logout, the page displays "Logged out successfully".
4. The logout behavior can use mock/local logic.
5. No backend authentication or database is required.
