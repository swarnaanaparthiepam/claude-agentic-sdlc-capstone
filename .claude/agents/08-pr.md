# Phase 08: Pull Request Agent

**Purpose:** Create GitHub pull request for verified implementation.

## Agent Contract

- **Phase:** 08 - PR
- **Role:** PR Coordinator
- **Invocation Modes:**
  - **Workflow Mode:** Invoked by workflow.md after Phase 07 approval
  - **Standalone Mode:** Can be invoked directly with User Story ID
- **Inputs:** All artifacts 00-07, feature branch, verification passed OR User Story ID
- **Outputs:** GitHub Pull Request
- **Prerequisites:** Phase 07 complete OR all artifacts exist + verification PASS
- **Approval Required:** No (workflow marks complete after PR created)

## Procedure

1. **Validate Prerequisites** - All artifacts exist and approved
2. **Ensure Branch Pushed** - feature/<USER_STORY_ID> on GitHub
3. **Prepare PR Description** - Summary, changes, evidence, checklist
4. **Create PR** - Use `gh` CLI or prompt user with instructions
5. **Update status.md** - Record PR URL
6. **Report** to workflow: SDLC complete

## Creating the PR

### Option A: Using GitHub CLI (gh)

```bash
# Ensure branch is pushed
git push -u origin feature/<USER_STORY_ID>

# Create PR
gh pr create \
  --title "<USER_STORY_ID>: <Title>" \
  --body "<PR description from template>" \
  --base main \
  --head feature/<USER_STORY_ID>

# Get PR URL
PR_URL=$(gh pr view --json url -q .url)
```

### Option B: Manual (if gh not available)

```
Provide user with:
1. PR title
2. Full PR description
3. Instructions:
   - Go to GitHub repository
   - Click "Pull Requests" > "New Pull Request"
   - Select base: main, compare: feature/<USER_STORY_ID>
   - Paste title and description
   - Create pull request
   - Copy PR URL
```

## Error Handling

### Branch Not Pushed
```
ERROR: Feature branch not on GitHub.
Run: git push -u origin feature/<USER_STORY_ID>
Then retry Phase 08.
```

### GitHub CLI Not Available
```
INFO: GitHub CLI (gh) not available.
Manual PR creation required.

Follow these steps:
1. Ensure branch pushed: git push -u origin feature/<USER_STORY_ID>
2. Go to: <repository URL>
3. Create PR: base=main, compare=feature/<USER_STORY_ID>
4. Use description provided below
5. Submit PR

<PR Title>
<PR Description>
```

### PR Creation Failed
```
ERROR: Failed to create PR.
Error: <error message>
Recovery: Check GitHub permissions, branch status, retry.
```

### Merge Conflicts
```
ERROR: Merge conflicts with main branch.
Resolution required before PR can be created.
Recovery: Resolve conflicts, commit, push, retry Phase 08.
```

## Post-PR Steps (Not Automated)

**Human responsibilities:**
1. Review PR on GitHub
2. Request reviews from team members
3. Address any PR feedback
4. Merge PR when approved
5. GitHub Action publishes to Confluence
6. Close Jira ticket (if workflow configured)

## Notes

- This phase completes the SDLC workflow
- PR merge is manual (not automated)
- Confluence publishing triggered by GitHub Action
- Never force-push or force-merge
- Preserve all commits and history
